# SSE Saloon Plugin

SSE Saloon Plugin adds Server-Sent Events (SSE) streaming to Saloon requests, yielding each event as
the server sends it.

```bash
composer require hosmelq/sse-saloon
```

Read the [full documentation](https://hosmelq.com/docs/sse-saloon).

## Development

Run the test suite with:

```bash
composer test
```
